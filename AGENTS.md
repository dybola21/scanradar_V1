# ScanRadar

Aplicação independente com TanStack Start, Netlify e Supabase. Preserve o protocolo 3, RLS, idempotência e confirmação de parada. Não execute a suíte contra o banco de produção. Antes de publicar, execute npm run check. Não reescreva histórico já publicado. Migrações novas devem ser incrementais; a migração inicial destina-se somente a banco vazio.
